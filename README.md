# 生日快乐 · 粒子树

一棵深蓝底色上的香槟金粒子树。它从 [moleculemmeng020425/christmas-tree](https://github.com/moleculemmeng020425/christmas-tree) 的交互式粒子树改来：保留聚合成形 / 散开的形态变化、辉光和轨道控制，改成一份克制的生日场景。

上游 README 写明以 MIT 许可发布。本仓库保留该许可，并在 [LICENSE](LICENSE) 中注明出处。

这个演示**不加载任何照片**，也**不会打开摄像头**。鼠标或触控就够了。照片和故事可以以后再接，当前没有相框，也没有图片请求。

## 运行

需要 Node.js 18 或更新版本。

```bash
npm install
npm run dev
```

开发服务器默认在 `http://127.0.0.1:5173/`。

构建并用本地预览打开生产包：

```bash
npm run build
npm run preview
```

预览默认在 `http://127.0.0.1:4173/`。`dist/` 是静态产物，需要通过静态服务器访问（例如 `npm run preview`）。本仓库不提供公开在线预览地址。

## 操作

- **散作星河**：粒子平滑散成一片星野
- **重聚成树**：粒子再聚回树形，树顶是一枚小金星
- **自动旋转**：开或关。拖动时会暂时让出控制
- 鼠标拖动，或在触控屏上单指滑动，可以旋转
- 滚轮或双指可以在一定范围内缩放

画面会按设备降低粒子数量、像素比和辉光强度。系统开启「减少动态效果」时，默认关闭自动旋转，并减弱闪烁。
